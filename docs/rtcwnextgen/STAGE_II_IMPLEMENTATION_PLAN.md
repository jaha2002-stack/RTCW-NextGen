# План Stage II

[Консолидированная директива](STAGE_II_SCOPE_DIRECTIVE.md) задаёт обязательные критерии. [Матрица приёмки](STAGE_II_ACCEPTANCE_REPORT.md)

| Фаза | Следующая проверка |
| --- | --- |
| P01 · Нативный игровой режим | Запустить общую игру поверх загруженного нативного мира с сущностями преобразованной карты. |
| P02-A · Native Map Compilation | Сохранять регрессии brushDef3, Valve 220, коллизий, видимости и маршрутизации. |
| P02-B · BSP Import & Conversion | Расширить проверку IBSP на разрешённые карты со специальными поверхностями, видимостью и коллизиями. |
| P02-C · Spatial Fidelity | Сравнить пространственные размеры и положения на карте с несколькими помещениями, уклонами и сложными переходами. |
| P03 · Materials & Assets | Проверить сопоставление дополнительных типов ресурсов. Сохранять стабильные имена материалов при замене текстур. |
| P04 · Native Player & Physics | Проверить бег, уклоны и взаимодействия на первой преобразованной игровой карте. |
| P05 · Native Gameplay & AI | Подключить нативных противников, оружие, урон, звук, анимацию и сценарий преобразованной карты. |
| P06 · Compatibility Baseline | Проверить прохождение и стабильность интегрированного Windows x64 RC перед приёмкой владельцем. |

Графическая модернизация отложена до приёмки Stage II.
