# План Native Playable Level Prototype

Подсистемы Stage II используют RBDoom3BFG и авторские данные для независимых инженерных проверок. История режима совместимости сохранена на предыдущей ветви. [Текущая архитектура](architecture.md) · [Ограничения](STAGE_II_BLOCKER_ANALYSIS.md)

| Фаза | Текущее состояние | Следующая проверка |
| --- | --- | --- |
| P01 · Native Engine Bootstrap | Пользователь подтвердил запуск, resize и выход в Windows x64/DX12. | Проверять регрессии диагностического лаунчера. |
| P02 · Level Pipeline | Пользователь подтвердил P02 на Windows. Relay Station компилируется в два render area с управляемым порталом, `.cm` и `.aas48`. | Проверить загрузку нового сценария на аппаратном DX12. |
| P03 · Materials & Asset Mapping | Текстуры пола и стен связаны с MTR. Полупрозрачная панель сохраняет детали фона. | Подтвердить картинку на Windows по карточке. |
| P04 · Native Player & Physics | RBDoom3BFG `idPhysics_Player` управляет камерой и перемещением. Сценарий включает ступень, прыжок, приседание, дверь и лестницу. | Пройти тот же маршрут на ПК. |
| P05 · Native Gameplay & AI | Подбор ячейки разблокирует дверь. Дрон идёт по AAS, триггер передатчика завершает уровень после прибытия дрона. | Подтвердить прохождение и перезапуск на ПК. |
| P06 · Baseline | Для Windows предусмотрен x64/DX12 RC с лаунчером Relay Station и диагностикой P01/P02. | Подтвердить Windows CI, опубликовать точный ZIP и получить игровую приёмку. |

Графические технологии Stage III требуют отдельного согласования после приёмки. [Матрица приёмки](STAGE_II_ACCEPTANCE_REPORT.md)
