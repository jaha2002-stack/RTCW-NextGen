# Relay Station · Windows x64

Распакуйте ZIP и запустите **Play Relay Station.cmd**. В сборку входят карта,
материалы и шейдеры, необходимые для запуска.

| Клавиши | Действие |
| --- | --- |
| `WASD` / мышь | Движение и обзор |
| `Space` | Прыжок |
| `C` | Присесть |
| `E` | Использовать |
| `R` / `Esc` | Начать заново / выйти |
| `F12` | Сохранить кадр |

1. Проверьте текстуру пола и полупрозрачную голубую панель справа от входа.
2. Пройдите по ступени, попробуйте прыжок и удерживайте `C` под низким коробом.
3. Подберите зелёную ячейку и попробуйте пройти сквозь закрытую дверь. Нажмите `E`, чтобы открыть её.
4. Посмотрите, как дрон движется к пункту назначения. Идите к золотой стене и удерживайте `W`, чтобы подняться по лестнице.
5. Дойдите до передатчика. Появится надпись **RELAY ONLINE**. Нажмите `R` и убедитесь, что дверь снова закрыта и ячейка на месте.

Кадр и `qconsole.log` сохраняются в папке текущего запуска под
`%LOCALAPPDATA%\RTCW-NextGen`. Путь к журналу показывается при запуске.
