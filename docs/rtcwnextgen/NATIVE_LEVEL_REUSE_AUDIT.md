# Аудит компонентов при переходе на нативные уровни

Ветвь `rtcwnextgen/stage-ii-native-level-remaster` основана на проверенном коммите `2525b4c1`. Ветвь `rtcwnextgen/phase-p02-bsp-metadata` содержит историю Variant A и документацию интерфейсов id Tech 3. [Прежняя архитектура](https://github.com/jaha2002-stack/RTCW-NextGen/blob/2525b4c175c7602c984f298a0f38381f9ffae9ad/docs/rtcwnextgen/architecture.md)

| Компонент | Решение для нативного конвейера |
| --- | --- |
| Windows x64/DX12, Vulkan, сборка и контрольные суммы | Переиспользуются. Windows ZIP включает `rbdmap` и утилиту сборки авторского уровня. |
| Инвентарь PK3 и разбор IBSP | Переиспользуются как отдельные средства диагностики файлов и заголовков. |
| Разделение путей `--state-dir` | Остаётся для офлайн-диагностики. Нативная сборка использует отдельное временное дерево и новый выходной каталог. |
| `dmap` и `rbdmap` | `rbdmap -nogui` читает текстовый MAP через `idMapFile` и собирает нативные геометрию, коллизии и AAS. `brushDef3` и Valve 220 прошли проверку. |
| `convertMapQuakeToDoom` | Консольная команда читает текстовый Valve 220 MAP, нормализует свойства сущностей и материалы и записывает карту. Команда способна переписать рабочий MAP. Новый конвейер использует прямой загрузчик Valve 220 в `rbdmap` во временном дереве. |
| `convertMapToValve220` | Консольный экспорт текстовой MAP для TrenchBroom. Результат `_valve220.map`. |
| `exportMapToOBJ`, Blender и TrenchBroom | Команда экспортирует MAP в OBJ/MTL для просмотра и редактирования сеток. Коллизии, AAS и игровые свойства требуют отдельного этапа. Проверено чтение Valve 220. Запуск редакторов остаётся `NOT TESTED`. |
| Game, CGame, UI, движение, AAS и скрипты id Tech 3 | Перенос исключён из обязательного объёма. Последующие авторские сцены используют нативные системы RBDoom3BFG. |
| Декларации, физика, сущности и AI RBDoom3BFG | Два материала и нативный render world проверены в кадре. Генерация `.cm` и `.aas48` подтверждена. Три точечные трассы прошли. Сущности, движение игрока и AI требуют испытаний. |
