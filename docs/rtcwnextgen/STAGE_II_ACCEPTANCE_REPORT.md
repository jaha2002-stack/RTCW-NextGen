# RTCW NextGen — приёмка Native Playable Level Prototype

Текущая архитектура использует нативные подсистемы RBDoom3BFG. Полное сохранение планировки `escape1` в новой карте подпадает под ограничение на воссоздание уровней существующей игры. Работы по сборке и проверке авторской геометрии ведутся независимо. [Ограничения](STAGE_II_BLOCKER_ANALYSIS.md)

| Критерий Stage II | Статус | Доказательство или зависимость |
| --- | --- | --- |
| Запуск на RBDoom3BFG | PARTIAL | Windows x64/DX12 подтверждён компиляцией. Нативный предпросмотр запущен под Linux/Vulkan. |
| Загрузка целевой карты в игровом режиме | BLOCKED | Нативный render world проверен на авторской карте. Загрузка точной планировки исходного уровня входит в операцию с `POLICY_BLOCKER`. |
| Структура, координаты и масштаб | PARTIAL | У исходного авторского Valve 220 проверены восемь углов помещения и материал панели. Сохранение исходной структуры `escape1` заблокировано. |
| Перемещение игрока | NOT IMPLEMENTED | Передача координат начальной точки в камеру проверена. Управление игроком в новом игровом режиме отсутствует. |
| Физика и коллизии | PARTIAL | `.cm` скомпилирован. В нативном менеджере коллизий подтверждены попадания в стену и пол и свободная трасса. Физика игрока пока не проверена. |
| Игровые механики | NOT IMPLEMENTED | Нативная игровая сцена с предметами и уроном отсутствует. |
| AI | PARTIAL | На авторском входе `.aas48` содержит одну достижимую область. Движение AI ещё не испытано. |
| Интерактивные объекты | NOT IMPLEMENTED | Двери и триггеры нового сценария отсутствуют. |
| Завершение целевого уровня | BLOCKED | Целевой игровой кандидат требует воссоздания планировки оригинального уровня. |
| Отсутствие критических ошибок в игре | NOT TESTED | Подтверждены загрузка, снимок после изменения окна и выход по Escape в предпросмотре. |
| Windows x64 сборка для игровой приёмки | NOT IMPLEMENTED | Доступна инженерная упаковка компилятора, движка и диагностических компонентов. Аппаратный DX12 и игровой RC не подтверждены. |

На Linux 17 автоматических тестов прошли. Для авторской карты проверены `.proc`, `.cm`, `.aas48`, сохранение байтов входа и отказ при отсутствии ожидаемого AAS. Отдельно повторён тест загрузки нативного мира и цвета материалов под Vulkan validation. Сценарий для пользовательской игровой приёмки и тег Native Playable Level Prototype RC отсутствуют.
