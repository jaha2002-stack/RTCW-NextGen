# RTCW NextGen — приёмка Native Playable Level Prototype

Для P03–P06 подготовлен самостоятельный авторский сценарий Relay Station на нативном RBDoom3BFG. [Архитектура](architecture.md) · [Ограничения исходного варианта](STAGE_II_BLOCKER_ANALYSIS.md)

| Критерий | Проверка |
| --- | --- |
| P01 · Запуск, resize, Escape | Пользователь подтвердил Windows x64/DX12 для диагностической сборки. |
| P02 · Нативная загрузка и коллизии | Пользователь подтвердил P02. В Relay Station есть два render area, дверной портал, коллизии и несколько навигационных областей. |
| P03 · Текстуры и прозрачность | Проверка пикселей Vulkan определяет рисунок пола и просвечивающий фон за тонированной панелью. |
| P04 · Игрок и физика | Сценарий Vulkan проверяет прыжок, ступень, проход под коробом при приседании, сопротивление закрытой двери и подъём на площадку. |
| P05 · События и AI | Перемещение по AAS, сбор ячейки, открытие двери и завершение на передатчике проверяются в одной игровой сессии. |
| P06 · Стабильность и артефакт | Проверка Vulkan требует прохождения, перезапуска и штатного выхода. Windows CI компилирует DX12/DXIL и проверяет ZIP. Игровая приёмка DX12 Relay Station проводится по карточке. |
