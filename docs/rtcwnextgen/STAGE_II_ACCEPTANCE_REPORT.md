# RTCW NextGen — приёмка Compatibility Prototype

**Итоговая пользовательская приёмка пока недоступна.** Утверждён Variant A с RBDoom3BFG как основным движком. Критерии ниже соответствуют пересмотренному объёму Stage II от 27.11.2026. Итоговый запуск и полное прохождение конкретного оригинального уровня `escape1` с его игровыми сценариями подпадают под `POLICY_BLOCKER`. Диагностические инструменты, форматные проверки и новые адаптеры общего назначения имеют собственные статусы. [Причины и доступные проверки](STAGE_II_BLOCKER_ANALYSIS.md)

## P01–P06

| Фаза | Статус | Результат |
| --- | --- | --- |
| P01 · Запуск и ресурсы | IN PROGRESS | Сборка Windows x64/DX12 и синтетический запуск проверены. Офлайн-поиск в PK3 и разделение путей реализованы. Игровой режим и загрузка ресурсов из движка остаются `NOT IMPLEMENTED`. |
| P02 · Мир и файлы ресурсов | IN PROGRESS | Заголовок `IBSP` v47, секции и размеры записей проверены. Диапазоны вершин и индексов подтверждены на авторских данных. Передача геометрии и материалов в нативный мир остаётся `NOT IMPLEMENTED`. |
| P03 · Игрок и коллизии | NOT IMPLEMENTED | Компилятор генерирует карту и коллизии для авторского теста. Контракты управления и симуляции для режима совместимости ещё отсутствуют. |
| P04 · Игровые модули | NOT IMPLEMENTED | Проверены точки входа и разница контрактов Game/CGame. Переход к игровой логике зависит от реализованных адаптеров. |
| P05 · AI, навигация и скрипты | NOT IMPLEMENTED | Найдены входы загрузки навигации и скриптов. Адаптеры событий, навигации и миссий ещё отсутствуют. |
| P06 · Игровой кандидат | BLOCKED | Отсутствует допустимый игровой кандидат для прохождения оригинальной карты. Инженерные сборки и проверки ZIP доступны независимо. |

## AC-01–AC-12

| Критерий | Статус | Фактическая проверка или оставшаяся зависимость |
| --- | --- | --- |
| AC-01 · Самостоятельная Windows x64 сборка | NOT IMPLEMENTED | Windows x64/DX12 собирает самостоятельную диагностическую программу. Исполняемый режим совместимости не реализован. |
| AC-02 · Ресурсы пользовательской установки | IN PROGRESS | Чтение заголовка из локального PK3 проверено. Требуется интерфейс загрузки ресурсов из игрового режима. |
| AC-03 · Реальная карта | BLOCKED | Подтверждены `IBSP` v47 и 17 секций целевого файла. Полноценное отображение оригинального уровня в составе требуемой сборки затронуто ограничением на воссоздание конкретной игры. |
| AC-04 · Управление и камера | NOT IMPLEMENTED | Адаптер игрока для целевого режима отсутствует. |
| AC-05 · Физика и коллизии | NOT IMPLEMENTED | Компиляция коллизий на тестовой карте проверена. Физика и взаимодействие в игровом режиме отсутствуют. |
| AC-06 · Механики и взаимодействия | NOT IMPLEMENTED | Нужен игровой модуль с сущностями, событиями и взаимодействиями. |
| AC-07 · AI | NOT IMPLEMENTED | Подключение навигации, состояний и действий ещё не реализовано. |
| AC-08 · Сценарии и триггеры | NOT IMPLEMENTED | Исполнитель событий и сценариев в режиме совместимости отсутствует. |
| AC-09 · Звуки и анимации | NOT IMPLEMENTED | Проверены исходные API. Требуются работающие адаптеры и функциональные испытания. |
| AC-10 · Полное прохождение карты | BLOCKED | Стандартное прохождение конкретного оригинального уровня входит в операцию с `POLICY_BLOCKER`. |
| AC-11 · Базовый графический конвейер | NOT TESTED | Подтверждены Vulkan на Linux и компиляция DX12 на Windows для диагностической программы. Требуется проверка графического профиля рабочего режима совместимости. |
| AC-12 · Стабильность игрового процесса | NOT TESTED | Проверки аварий, блокирующих дефектов и производительности требуют исполняемого игрового сценария. |

**DEFERRED** — оригинальные меню, HUD, настройки и экраны загрузки, система сохранения, полная кампания, дополнительные виды оружия и AI вне целевой карты, визуальная идентичность, окончательная оптимизация и модернизация графики. Временный интерфейс и запуск через аргументы допустимы для технической проверки. Stage III требует отдельного согласования после игровой приёмки.

## Доказательства и выпуск

- Реализованы и проверены `--locate`, `--state-dir`, `--bsp-info` и проверка ссылок поверхностей в авторском BSP. Проверки запускаются на исходниках ветви `rtcwnextgen/phase-p02-bsp-metadata`. [Команды и результаты](TESTING.md) · [Прогресс](STAGE_II_PROGRESS.md)
- Сравнение с оригиналом ограничено форматом данных, порядком поиска и интерфейсами исходного кода. Прохождение, кадры, поведение AI и производительность оригинальной карты в RBDoom3BFG не проверялись. [Архитектурный аудит](architecture.md)
- Ранее исправлены чёрный кадр в синтетическом режиме, очистка семафора Vulkan и обработка ненулевого кода выхода в лаунчере Windows. Проверенная диагностическая сборка относится к `5edfbac2e42c8d6d1747607c9297121948d5e5d8`. [Результаты базовой проверки](https://github.com/jaha2002-stack/RTCW-NextGen/actions/runs/45915942732)
- Игровой Release Candidate, его тег, контрольные суммы, инструкция запуска и журнал игрового режима появятся только для допустимого проверенного кандидата. Реестр пользовательской приёмки остаётся пустым. [Реестр](ACCEPTANCE.md)
