# RTCW NextGen — статус приёмки Stage II

**BLOCKED** · 27.11.2026

Условие Stage II — воспроизведение оригинальной Return to Castle Wolfenstein в RBDoom3BFG, включая полное прохождение `escape1`, оригинальный интерфейс, механику и сценарии. Реализация такого воспроизведения выходит за допустимые рамки этой работы. Кандидат Stage II, тег, контрольные суммы релиза и инструкции по установке недоступны. Реестр пользовательской приёмки пуст.

## Подтверждённые проверки

- Linux `rbdmap` собран. Девять автоматических тестов прошли с кодом 0. Покрыты компилятор карты, правила упаковки, приоритет архивов, диагностика отсутствующих файлов и разделение путей.
- В тесте CLI отдельный каталог принят с кодом 0. Путь внутри установки и ссылка на `Main` отклонены с кодом 1. Содержимое всех синтетических PK3 совпало побайтово, а запрошенный каталог сохранений остался отсутствующим. [Инструкция по воспроизведению](TESTING.md)
- С оригинальным iortcw сопоставлялся порядок поиска ресурсов. Сравнение прохождения, игровой физики, AI, аудио и кадров не проводилось. [Сверенный поиск в iortcw](https://github.com/iortcw/iortcw/blob/438e7d413b5f7277187c35b032eb0ef9093ae778/SP/code/qcommon/files.c#L3197)
- В синтетическом рендерере ранее устранены чёрный кадр, утечка семафора Vulkan при завершении и неверная обработка ненулевого кода выхода Windows. Исходный коммит диагностической сборки `860c6158f157f8226e4810847d5bf00eebad32e1`. [Ранее проверенный Windows CI](https://github.com/jaha2002-stack/RTCW-NextGen/actions/runs/45912107216)
- Изменение проверки путей сохранено в `rtcwnextgen/phase-p01-state-preflight`. [Windows CI этой ветки](https://github.com/jaha2002-stack/RTCW-NextGen/actions?query=branch%3Artcwnextgen%2Fphase-p01-state-preflight)
